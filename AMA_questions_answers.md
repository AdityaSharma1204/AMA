# AMA - Questions and Answers

### 1. What is the difference between `find` and `grep` in CLI?
`find` searches for files and directories based on names, types, sizes, etc.  
`grep` searches for specific text or patterns inside files.

### 2. What is the difference between `/` and `//`?
`/` is used for normal division and returns a decimal (float), e.g. 10 / 3 → 3.333....
`//` is used for floor division and returns the quotient rounded down, e.g. 10 // 3 → 3.

### 3. How do you initialize a Git repository in a local system?
Open the project directory in the terminal and run `git init`.  

### 4. What is a dynamically typed language?
In a dynamically typed language, variable types are checked during runtime.  
A variable can hold values of different types without explicitly declaring its type.

### 5. How do you log in to a PostgreSQL database?
Use the command `psql -U username -d database_name` in the terminal.  

### 6. How do you remove a file using CLI?
Use the `rm filename` command in Linux or macOS terminals.  
For example, `rm test.txt` removes the file named `test.txt`.

### 7. What does `grid-column: 1 / 4` mean?
It makes a grid item start at column line 1 and end at column line 4.  
Therefore, the item spans across three grid columns.

### 8. What is a SAVEPOINT in SQL?
A `SAVEPOINT` creates a point inside a transaction that you can roll back to.  
It allows you to undo part of a transaction without cancelling the entire transaction.

### 9. Why do we use an abstract class?
An abstract class provides a common structure and can define methods that subclasses must implement.  
It is useful for sharing common behavior while preventing direct creation of its objects.

### 10. What are HTML attributes?
HTML attributes provide additional information or settings for an HTML element.  
They are written inside the opening tag, such as `class="box"` or `id="main"`.

### 11. What is the difference between a while loop and a for loop?
A `while` loop is generally used when the number of iterations is not known beforehand.  
A `for` loop is commonly used when iterating over a range, array, or known number of times.

### 12. What are the attributes of the `<img>` tag?
Common attributes include `src` for the image path and `alt` for alternative text.  
Other useful attributes include `width`, `height`, `title`, and `loading`.
