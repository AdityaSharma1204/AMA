# AMA

## 1. What is an agent?
An agent is an AI system that works toward a goal by deciding what steps to take and using tools when needed.
Unlike a basic chatbot, it can take actions such as searching files, calling APIs, or running code.

## 2. What is the agent loop?
The agent loop is the repeated cycle of understanding a task, choosing an action, and using a tool or responding.
It then observes the result and repeats until the task is complete or it needs clarification.

## 3. What is the difference between `CLAUDE.md` and a Skills file?
`CLAUDE.md` contains project context and general instructions Claude should follow while working.
A Skills file gives Claude reusable instructions for a specific task or workflow.

## 4. What is the Claude API?
The Claude API lets developers use Claude models inside their own applications.
An app sends input to the API and receives a response, enabling features such as chat, summarization, and analysis.

## 5. What is an MCP server?
An MCP server is a program that provides AI applications with tools, resources, or prompts through the Model Context Protocol.
It can connect an assistant to services such as files, databases, and APIs.

## 6. How do you connect to an MCP server?
Configure a compatible client with the MCP server details and any required credentials or environment variables.
Then restart or refresh the client if needed, approve the requested permissions, and test the available tools.

## 7. What is Claude for Chrome?
Claude for Chrome is a browser integration that lets Claude help with webpages and browser-based tasks.
Its actions depend on available features and permissions, so review access and confirm important actions.
