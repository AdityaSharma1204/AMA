# AMA Questions and Answers

## 1. What is a constructor?

A constructor is a special method used to initialize an object when it is created. In Python, the constructor is written as __init__().

## 2. What is the super() method?

super() is used to access methods and variables of the parent class. It is commonly used to call the parent class constructor.

## 3. What is a has-a relationship?

A has-a relationship represents composition or aggregation between classes. For example, a Car has an Engine.

## 4. What is the staging area?

The staging area is where we keep changes before committing them to Git. The git add command is used to move changes to the staging area.

## 5. Which command is used to change branches?

The git switch command is used to change branches. Example: git switch leaf.

## 6. What is polymorphism?

Polymorphism means one interface can have different implementations. In Python, the same method can behave differently for different objects.

## 7. What is a class method?

A class method is a method that works with the class rather than a specific object. It is created using the @classmethod decorator and takes cls as its first parameter.

## 8. What is the difference between WHERE and HAVING?

WHERE filters individual rows before grouping. HAVING filters groups after using GROUP BY.

## 9. How do you merge two branches?

First, switch to the branch where you want to merge the changes. Then use git merge branch_name.

## 10. What are class variables and instance variables?

A class variable is shared by all objects of a class. An instance variable belongs to a particular object.

## 11. What is the purpose of the df command?

The df command is used to check available and used disk space on file systems. It displays the information in blocks by default.

## 12. What is LSP in SOLID?

LSP stands for Liskov Substitution Principle. It states that objects of a child class should be usable wherever objects of the parent class are expected without breaking the program.

## 13. What is the difference between a list and a dictionary?

A list stores values in an ordered sequence and uses indexes. A dictionary stores data as key-value pairs.
